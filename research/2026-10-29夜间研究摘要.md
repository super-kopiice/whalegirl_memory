# 鲸鱼娘长期记忆阶段研究摘要

研究时段：2026 年 10 月 28 日晚至 29 日早；整理发布：2026 年 10 月 29 日。时区：Asia/Shanghai。

本项目研究 DeepSeek Harness（DSH）中的鲸鱼娘，也称大肥鱼，如何在有限上下文和可控成本下延续共同经历。**本阶段的核心判断是：可靠的长期记忆，需要把保存、检索、更新和使用分别做好。更大的记忆库或更多摘要，不能单独解决旧事实、错误推断和删除复活的问题。**

本次梳理了 11 个相关项目，重点静态核查 dsh-fish-memory 的关键代码及测试设计，并整理人类与动物记忆实验。没有安装或运行记忆系统，没有独立性能实测；视频证据主要为公开简介和可访问文字。下述方向用于安排研究，不构成效果排名。

## 四项主要发现

**共同经历需要保留来源和语境。**“我们讨论过旅行”“你说自己去过旅行”“角色想象一起旅行”是不同来源。摘要若丢失主体、否定、假设和时间，就可能把角色表达变成真实经历。原始记录、事件、事实与推断应能关联，也应允许分别修订。[研究主报告](鲸鱼娘长期记忆研究.md)

**当前状态和真实历史需要同时成立。**“去年住杭州，今年搬到成都，今天回忆杭州生活”至少包含事件发生、系统得知和事实有效三种时间。最近写入的内容不必然代表最新状态；重要的内容也不必然永久有效。需要分别评价“当时住哪里”和“现在住哪里”。[时间与更新核查](DSH记忆插件关键路径核查.md)

**离线整理需要受证据约束。**人类睡眠重激活实验的收益依赖线索、任务和状态，不能推出模型自由写日记必然改善记忆。值得比较不整理、基于原始出处的整理和自由反思，并观察新错误、来源丢失及成本。同一推断被反复总结，不等于获得了更多独立证据。[人类机制专题](人类记忆机制与工程类比边界.md)

**想不起来和删除是不同问题。**一次“忘记”可能发生在写入、检索或回答使用阶段。降低召回优先级、标记事实过期、归档压缩、删除指定副本，各有不同含义。删除还必须考虑摘要、缓存、复制的会话、备份和未完成任务。[删除与复制核查](DSH记忆插件关键路径核查.md)

## 方案应按问题选择

通用引擎在夜间阶段主要经过项目文档与部分论文初筛，核查深度不同于 fish-memory。下表是候选场景判断，更具体的实现边界需后续固定版本源码研究。

| 研究对象 | 值得解决的问题 | 需要继续验证的边界 |
|---|---|---|
| dsh-fish-memory | 日常往事、中文词法检索、可解释的召回过程 | 时间、纠正优先级、触发门槛、跨会话副本 |
| dsh-mnemon | DSH 记忆编排、多后端接入与管理 | 更换后端后的可见时间、改写和删除语义 |
| dsh-whale-persona | 角色表达连续性、共同经历和用户观察的使用规则 | 人物设定不能保证底层记忆正确 |
| whale-notify | 通知渠道、聊天工作流、会话总结和群聊相关记忆 | 词面检索、稳定身份和隔离 |
| Hindsight | 跨事件回顾、关联和有依据的综合理解 | 抽取与反思的来源支持、延迟和费用 |
| Graphiti | 事实与关系变化，区分当时与现在 | 实体识别、冲突判断和图服务复杂度 |
| Mem0 | 偏好记忆与个性化应用接入 | 开源与托管能力及评价条件差异 |
| Honcho | 用户偏好和跨情境理解 | 推断误判、暂定状态和纠正机制 |
| Letta | 代理运行、持久状态与记忆的一体化管理 | 接入迁移范围、模型工具调用要求 |
| EverOS | 可读可迁移的记忆整理、经历和经验复用 | 版本演变、旧材料与当前实现差异 |
| MemoryBank / SiliconFriend | 陪伴记忆、用户理解和遗忘机制的研究参照 | 有限实验与多年实际使用的距离 |

各项目链接与详细依据见[主报告的方案比较](鲸鱼娘长期记忆研究.md)。

## DSH 插件的六个关键边界

以下结论限定于 `dsh-fish-memory@8b3571da94d8bafd12f746ad4b2035186f5c014c`，是给定条件下的代码路径判断，未测实际触发频率。

| 代码路径 | 条件与可能结果 |
|---|---|
| 低信息输入提前返回 | 说话统计样本达到 20 且输入低于门槛时，该注入路径跳过常驻事实；其他上下文仍可能提供信息 |
| 最高重要度映射稳定事实 | 重要的临时状态可能获得长期待遇 |
| 写入时使用当前时间 | 今天补记旧事，可能与相对时间前缀冲突 |
| 每日配额先于纠正 | 达到配额时，纠正也可能被明确拒绝 |
| 子串去重先于取代 | 在旧句末尾追加否定的特定文本会强化旧条目并提前返回 |
| 跨会话复制独立快照 | 来源纠正或删除，不能推定会传播到副本 |

该项目也有实质防护：区分相关性与鲜活度，单纯召回不自动强化记忆，以删除标记和清理代际阻止旧任务恢复已删内容，并提供相应测试设计。本次阅读了相关测试，没有执行。

作者“43%→91%”数字在代码注释中限定为 **40 句真实问句的前 3 名精确度**，不能解释为长期记忆整体准确率。具体行号、适用条件与八组待执行合成验证，见[关键路径专题](DSH记忆插件关键路径核查.md)。

## 人类记忆研究可以支持什么

可塑性、线索提取、情境区分和可更新性值得转化为工程假设；不能把突触、海马、睡眠与文件、数据库、后台摘要直接等同。部分证据来自动物实验，部分结论存在外推和复现限制。

主动遗忘专题同时保留支持研究、元分析和未复现结果。提取受到抑制不等于数据被物理删除；能回忆约定也不等于能按时履行。具体论文、版本和阅读范围见[来源台账](人类记忆机制与工程类比边界.md)。

## 下一阶段的研究问题

优先收窄到“共同经历可靠回忆”和“用户变化后正确更新”，再围绕反思失真检查来源与修订传播。后续评测需要固定基础模型、人物设定、数据与预算，与最近历史、滚动摘要、原始记录检索比较。

| 待解决问题 | 所需证据 |
|---|---|
| 中文同义表达、省略、否定和角色扮演的可靠性 | 合成材料与统一评分，分开观察写入、检索和回答 |
| 多轮摘要与反思是否累积错误 | 连续整理实验，追踪新增断言与原始出处 |
| 历史、当前状态、纠正和删除能否一致 | 时间更新、旧记录晚到、复制与在途任务反例 |
| 长期使用是否可承受 | 抽取、检索、重排、回答、离线整理的总调用与等待时间 |
| 更换模型后角色能否延续 | 相同资料和预算下的行为比较 |

视频完整字幕、通用引擎更深入的源码与测试、人类自然生活的多年记忆，以及公开基准的完整复核，均保留为后续工作。本次发布不包含已实现产品、已通过验收的 v1.0 或性能承诺。
